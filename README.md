Financial analysis project comparing Dabur India and Nestlé India using return analysis, beta, CAGR, HPR, variance, and risk metrics against the NIFTY 50 index.
# Dabur vs Nestlé Risk & Return Analysis

## Overview
This project analyses the risk and return performance of Dabur India and Nestlé India using simulated monthly stock price data from 2020–2025.

## Key Concepts Used
- Holding Period Return (HPR)
- CAGR
- Beta Analysis
- Variance & Standard Deviation
- Systematic & Unsystematic Risk
- Comparative Financial Analysis

## Tools Used
- Excel
- Financial Modeling
- Statistical Analysis

## Companies Analysed
- Dabur India Ltd.
- Nestlé India Ltd.
- NIFTY 50 Benchmark

## Outcome
The project evaluates defensive FMCG stock behaviour and suitability for risk-averse investors.
